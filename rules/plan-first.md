# 先方案后执行（Plan-First）

1. 用户以咨询口吻发起变更，或任务存在多方案/影响面不明确时：
   动手前先输出【方案 + 推荐】：改动清单（文件路径·要点）、影响面、
   可选方案及推荐项与理由；等待用户选择或确认后再动手。
2. 豁免：用户已给出明确执行指令（目标与动作明确，如"改一下/实现/
   按 X 方案做/写入某文件"），或本会话已确认过方案的，直接执行，
   不再重复方案确认。
3. 确认或豁免后，按既定方案连续自动执行到底：每阶段做真实验证
   （编译/测试）后直接进入下一项，禁止中途停下等"继续"。
4. 执行中若出现超出已确认方案的新决策点，暂停并再次给出选项+推荐；
   不影响方案的小实现细节自行按最佳实践决定。
5. 纯提问/咨询/评审不改文件。分析型问题（原因/根因/日志/评估）
   直接给出分析结论与证据，不套方案模板；若结论指向需要修复，
   再附修复方案+推荐待用户确认。
